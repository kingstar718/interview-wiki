# 136. 只出现一次的数字（Single Number）

频次 ★★★★ · 难度 🟢 · 高频：全厂

## 题目

非空整数数组，除了某个元素只出现一次，其余都出现两次。找出那个只出现一次的。

## 思路

**异或**：`a ⊕ a = 0`，`0 ⊕ a = a`。全部异或一遍，结果就是只出现一次的数字。

## 代码

```java
public int singleNumber(int[] nums) {
    int res = 0;
    for (int n : nums) res ^= n;
    return res;
}
```

## 异或物理本质与湮灭模型（二阶段 5/50 实测）

```
XOR 定义：逐位比较相同→0 不同→1（位间无进位 → 位独立 → 交换/结合律成立）
两律推导：a⊕a=0（每位"自己 vs 自己"必相同）；a⊕0=a（0 是透明人：贴谁显谁）
"不相同为 1"≠"为原数"——原数保留是 ⊕0 的结果不是规则
全局奇偶观：每一位统计 1 出现次数，奇→1 偶→0——顺序无关的深层原因（先排后配都行）
湮灭模型：相同的数相遇即湮灭、0 透明、单飞者留底——初值 0 只是透明起点
后续关卡：169 摩尔投票（计数抵消）、260 两单飞（分组异或）
```

## 复杂度

- **时间**：O(n)
- **空间**：O(1)

## 边界条件

- 长度 1：返回唯一的那个元素
- 全正/全负：异或不受符号影响

## 变式

- **[260. 只出现一次的数字 III](260-single-number-iii.md)**：有两个只出现一次的数
- **137. 只出现一次的数字 II**：其余出现三次，用位运算统计每位

## 易错点

- 异或的性质要记牢：`a⊕0=a`、`a⊕a=0`、交换律结合律
- 不能用加减法替代——异或是本题的唯一最优解

## 面试追问

- **如果其他数字出现三次而不是两次？** 逐位统计每个 bit 的出现次数，模 3 取余。不能用异或了
