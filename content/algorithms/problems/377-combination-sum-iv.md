# 377. 组合总和 IV（Combination Sum IV）

频次 ★★★ · 难度 🟡 · 高频：字节

## 题目

不同整数数组 nums，找出总和为 target 的元素组合个数（**顺序不同的序列视为不同组合**）。

**示例**：
```
输入: nums = [1,2,3], target = 4
输出: 7  （(1,1,1,1), (1,1,2), (1,2,1), (1,3), (2,1,1), (2,2), (3,1)）
```

## 思路

**完全背包求排列数**：`dp[i]` 表示凑成 i 的排列数。

`dp[i] += dp[i - num]` for each num ≤ i。

**关键**：外层遍历金额 i，内层遍历硬币 num。这与 518 题（组合数）内外层相反。因为排列考虑顺序，外层金额意味着"走到金额 i 时，最后一步可以用任意硬币"，这样不同顺序会被重复计数成不同方案。

## 代码

```java
public int combinationSum4(int[] nums, int target) {
    int[] dp = new int[target + 1];
    dp[0] = 1;                               // 凑 0 有一种方式
    for (int i = 1; i <= target; i++) {       // 外层：金额（排列数）
        for (int num : nums) {                // 内层：硬币
            if (i >= num) {
                dp[i] += dp[i - num];
            }
        }
    }
    return dp[target];
}
```

## 末步分箱——"外层容量 = 排列"的物理定型（实测 [1,2] target=3）

```
序列 = 0→target 的一条走路，每 num=一步
dp[i] = "0 走到 i 站的路条数"；dp[0]=1 原地
dp[3]（=dp[2]+dp[1]）读作："末步 1"箱（先到 2 的 2 条）+ "末步 2"箱（先到 1 的 1 条）= 3
(1,2) 落"末步 2"箱、(2,1) 落"末步 1"箱——顺序天然分开数 ← 排列的本质
518 外层=面额：面额配比相同 → 同箱只数一次 → 组合
```

- 内层 for-each 无"正/倒序"讲究（num 间互引用不存在）；nums[i] 可能 > i → 必须 `if (i ≥ num)`（[9] target=3 守）
- **结构换骨架**：外层 i 从 1..target 自增（不是 for-each 物品的滚表模板）——上界 `<=`（首个版 `<` 踩 off-by-one，全 0）
- LCS 签名以题面为准 `(int[] nums, int target)`（与 518 的 `(int amount, int[] coins)` 不同序——别凭记忆）

## 复杂度

- **时间**：O(target × n)，n = nums 长度
- **空间**：O(target)

## 边界条件

- target = 0：返回 1
- nums 中有超出 target 的数：跳过
- 结果可能溢出：题目保证结果在 int 范围内，但中间量可能超过，实际提交时注意

## 易错点

- **内外层顺序是核心**：外层金额 = 排列，外层硬币 = 组合。这道题和 518 的唯一区别
- 题目虽然叫"组合总和 IV"，但实际求的是**排列数**（顺序不同算不同）
- 注意 dp 数组可能越界，LeetCode 题目保证结果在 int 范围，但中间值可能溢出（C++ 需用 unsigned int，Java 可以）

## 面试追问
