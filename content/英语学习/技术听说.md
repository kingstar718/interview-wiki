# 技术听说

等级 L3-L4 · 每天 10 分钟 · 场景:练发音→一、发音纠正：中国工程师高频发音坑,听演讲→四、听懂技术演讲,技术讨论→三、技术讨论常用句式,站会→三、技术讨论常用句式

> **清晰度 > 口音。** 对方能听懂你说的技术内容，比发音像母语者重要 100 倍。中国工程师的发音问题高度集中在下面这几类音上，逐个纠正就能显著提升清晰度。

## 一、发音纠正：中国工程师高频发音坑

### th — 咬舌音

| 错误 | 正确 | 练习 |
|------|------|------|
| think → sink | 清音 /θ/：舌尖轻触上齿，只出气不振动声带 | think → three → through → thread |
| this → zis | 浊音 /ð/：舌位相同，但声带要振动 | this → that → those → the |

**关键**：舌尖必须伸出来碰到上齿，不碰 = 发错。两个 th 舌位一样，区别只在声带振不振动——摸着喉咙念 `think` / `this`，后者应该有震感。

### v / w

| 错误 | 正确 | 练习 |
|------|------|------|
| very → wery | v: 上齿碰下唇 | very → validate → version → value |
| we → ve | w: 圆唇，不碰 | we → work → window → web |

**关键**：v 上齿必须碰下唇，w 不碰。

### 词尾辅音吞掉

| 错误 | 正确 | 练习 |
|------|------|------|
| and → an | 发出 d | and → end → send → find |
| don't → don | 发出 t | don't → can't → won't → isn't |
| big → bi | 发出 g | big → bug → log → debug |

**关键**：词尾辅音必须发出来，否则意思全变（can vs can't，cash vs catch，log vs lock）。

### 长短元音

| 错误 | 正确 | 练习 |
|------|------|------|
| ship → sheep | /ɪ/ 短而松，/iː/ 长而紧 | ship / sheep, bit / beat, sit / seat |
| pull → pool | /ʊ/ 短而松，/uː/ 长而紧 | pull / pool, full / fool |

**关键**：长元音要拉长，短元音要短促。注意长短之外还有松紧——/ɪ/ 不是"短的 /iː/"，嘴角也更放松。

### 易混元音（不是长短问题）

| 错误 | 正确 | 练习 |
|------|------|------|
| bad → bed | /æ/ 开口大、舌位低，/e/ 开口小 | bad / bed, man / men, pan / pen |
| cat → cut | /æ/ 舌位靠前，/ʌ/ 靠中后 | cat / cut, bad / bud, ran / run |

**关键**：这几组都是**短元音之间**的对立，靠开口度和舌位区分，拉长发音不解决问题——念 `bad` 时下巴要明显放下来。

### l / r

| 错误 | 正确 | 练习 |
|------|------|------|
| light → right | l: 舌尖顶上颚；r: 舌尖后卷 | light / right, load / road, lock / rock |
| correct → collect | 同上 | correct / collect, grow / glow |

**关键**：l 舌尖顶上去，r 舌尖卷起来，完全不碰。

### 重音放错

| 错误 | 正确 | 说明 |
|------|------|------|
| DEvelop | deVElop | 重音在第二个音节 |
| archiTECture | ARchitecture | 重音在第一个音节 |
| mainTENance | MAINtenance | 重音在第一个音节 |
| DIStributed | disTRIButed | 重音在第二个音节 |
| CONfigure | conFIgure | 重音在第二个音节 |
| PArameter | paRAmeter | 重音在第二个音节 |

**关键**：不确定重音时，用 Google 翻译的发音按钮听一遍。

### n / l 不分（主要是南方口音）

| 错误 | 正确 | 练习 |
|------|------|------|
| line → nine | n: 鼻音；l: 舌尖顶上颚 | line / nine, low / no, light / night |

### z / s

| 错误 | 正确 | 练习 |
|------|------|------|
| is → iss | 浊音 z | is → has → was → does |
| zero → sero | 浊音 z | zero → zone → zoo |

**关键**：z 声带振动，s 不振动。

### 连读（linking）

| 分开读 | 连读 |
|--------|------|
| check it out | che-ki-tout |
| not at all | no-ta-tall |
| what are you | wha-da-ya |
| going to | gonna |
| want to | wanna |

**关键**：不要刻意连读。先追求清晰，连读在 L3 之后自然会发生。

### 语调：不要每个词都重读

**中文是音节等时（每个字差不多长），英文是重音等时（重音之间的时间差不多）。**

```
❌ I-WILL-WORK-ON-THE-PAYMENT-SERVICE
✅ I'll WORK on the PAYment SERvice
```

**关键**：只有关键词（名词、动词）重读，其他词（the、a、on、to）弱读。

## 二、影子跟读法（Shadowing）

### 是什么

跟着音频**同步朗读**，模仿语调、停顿、重音。这是提升发音和流利度最快的方法，没有之一。

### 怎么练

**Step 1**：选一段 30-60 秒的技术演讲/播客（带 transcript）
**Step 2**：盲听 2 遍，理解大意
**Step 3**：看 transcript 听 2 遍，标记听不懂的地方
**Step 4**：影子跟读 5 遍——跟着音频同步朗读，模仿一切
**Step 5**：录音，回听，标记"发音奇怪的地方"
**Step 6**：专门练那些奇怪的地方，直到能自然发出

**每天 10 分钟，坚持 3 个月，发音会有明显变化。**

### 推荐材料

| 材料 | 难度 | 特点 |
|------|------|------|
| ByteByteGo 视频 | 🟡 中 | 语速适中，发音清晰，内容是你熟悉的系统设计 |
| TechWorld with Nana | 🟢 易 | 语速慢，发音极清晰 |
| Google I/O / Apple WWDC 演讲 | 🔴 难 | 语速快，但发音标准，有完整 transcript |
| Software Engineering Daily 播客 | 🔴 难 | 有 transcript，覆盖各技术主题 |

## 三、技术讨论常用句式

### 描述你在做什么

| 说 | 场景 |
|-----|------|
| I'm working on [功能/模块]. | 正在做 |
| I'm looking into [问题]. | 正在调查 |
| I'm debugging [问题]. | 正在调试 |
| I'm adding [功能] to [模块]. | 正在加功能 |
| I'm refactoring [模块] to [目标]. | 正在重构 |
| I'm waiting for [依赖] to be [完成]. | 在等依赖 |

### 描述问题

| 说 | 场景 |
|-----|------|
| We're seeing [问题] in [环境]. | 我们在某个环境看到某问题 |
| The issue is that [描述]. | 问题是… |
| It looks like [推测]. | 看起来像是… |
| The root cause seems to be [原因]. | 根因好像是… |
| I suspect it's related to [怀疑]. | 我怀疑和…有关 |
| It's intermittent — happens about [频率]. | 偶发的，大概…频率 |

### 描述方案

| 说 | 场景 |
|-----|------|
| One approach is to [方案]. | 一个方案是… |
| Another option would be [方案]. | 另一个选择是… |
| The trade-off here is [权衡]. | 这里的权衡是… |
| The downside is [缺点]. | 缺点是… |
| The upside is [优点]. | 优点是… |
| In the long run, [长远的看法]. | 从长远看… |

### 确认理解

| 说 | 场景 |
|-----|------|
| Just to make sure I understand — you're saying [复述]? | 确认理解 |
| So the plan is [总结], right? | 确认计划 |
| Let me rephrase to make sure we're on the same page. | 重新表述以确认 |
| Does that sound right? | 这样对吗？ |
| Am I missing anything? | 我有遗漏吗？ |

### 表达不确定

| 说 | 场景 |
|-----|------|
| I'm not 100% sure, but I think… | 不太确定 |
| Don't quote me on this, but… | 别把我这话当权威 |
| Off the top of my head… | 凭印象说 |
| I'd need to double-check, but… | 需要确认一下 |
| Take this with a grain of salt, but… | 仅供参考 |

## 四、听懂技术演讲

### 听不懂的三个原因

1. **词汇不认识** → 背技术词汇（见 [技术英语词汇](技术英语词汇.md)）
2. **词汇认识但听不出来** → 发音和你以为的不一样，需要影子跟读纠正
3. **语速太快跟不上** → 需要适应不同语速和口音

### 听力训练三步法

**Step 1：盲听（2 遍）**
- 不看 transcript，只听
- 目标：理解大意（50% 即可）

**Step 2：对 transcript 听（2 遍）**
- 边看边听，标记"认识但没听出来"的词
- 这些词就是你的发音盲区，需要影子跟读重点练

**Step 3：精听（2 遍）**
- 逐句听，听不懂就暂停，回放
- 直到能听懂每一个词

### 适应不同口音

| 口音 | 特点 | 练习材料 |
|------|------|---------|
| 美式 | 儿化音（r 发音明显），语调起伏大 | 大部分技术演讲 |
| 英式 | 不卷舌，语调平 | BBC、English with Lucy |
| 印度 | r 弹舌，语调特殊，但词汇量好 | Gaurav Sen 视频 |
| 中式 | 音节等时，重音不突出 | 听自己的录音 |

**不要追求"听懂所有口音"，先追求"听懂标准美式"。** 其他口音在 L4 之后自然适应。

## 五、听不懂怎么办——现场急救

| 说 | 场景 | 语气 |
|-----|------|------|
| Sorry, could you say that again? | 没听清 | 礼貌 |
| Could you slow down a bit? | 对方太快 | 礼貌 |
| I didn't catch that last part. | 后半句没听清 | 自然 |
| What does [词] mean? | 有不认识的词 | 直接 |
| Let me make sure I understand — [复述]? | 确认理解 | 主动 |
| Sorry, I'm having trouble with the audio. | 线上会议听不清 | 借口 |

**关键**：听不懂就说听不懂，不要假装听懂了点头。假装听懂比承认没听懂要糟糕 100 倍。

## 常见追问

### 发音很差，能改过来吗？

**能改。但需要时间。** 发音是肌肉记忆，不是知识。需要每天 10 分钟影子跟读，坚持 3 个月才能看到明显变化。重点是：**不要试图一次纠正所有音，每次只练 1-2 个音。**

### 需要找外教吗？

**L3 之后可以找。** L1-L2 阶段，影子跟读 + 录音自检比自己瞎练有效得多。到了 L3 "能聊天"阶段，外教能给你真人反馈，纠正在自检中没发现的发音问题。每周 1-2 次，每次 30 分钟，性价比最高。

### 怎么判断自己发音进步了？

**录音。** 每个月录一段相同的英文（比如一段 Standup），对比上个月的录音。你会听到变化的。不要用"我觉得"判断，要听录音。

### 技术讨论时脑子一片空白怎么办？

**提前准备。** 技术讨论不是即兴演讲。开会前，把你可能说的 3-5 句话写下来，念熟。开会时，你只需要"回忆"而不是"创造"英文。随着练习增多，你需要的"提前准备"会越来越少。
