## 怎么用

1. **背八股**:左侧「面试专题」按学习顺序排列(Java → 框架 → 数据库 → 中间件 → 计算机基础 → 分布式与架构 → 工程实践 → 面试),每篇顶部有「面试追问地图」,先看地图再进正文。
2. **刷算法**:不知道从哪开始就按 [刷题方案](刷题方案.md) 走(两阶段路线,每章标了刷哪些跳哪些);要按套路查题就从 [算法题索引](算法题索引.md) 进 → 套路页讲「为什么这些题是同一类」,题目行尾的 `#技术词` 标签讲「具体用哪一招」;题解末尾的「变式/关联题」是串题的线索。
3. **冲刺大厂**:从 [高频题目索引](高频题目索引.md) 自上而下刷高频,按目标公司重点准备。
4. **补英语**:从 [英语学习索引](英语学习索引.md) 进 —— 不知道从哪开始就看「按等级学」,临时要写 PR / 开站会 / 面试就查「按场景查」,直达具体小节。
5. **用 AI 提效**:从 [AI提效索引](AI提效索引.md) 进 —— 先按 [AI提效方案](AI提效方案.md) 定级(L1 会问 → L5 会治理),再按场景查(让 AI 写测试、排线上问题、把 LLM 接进业务系统)。
6. **备考软考**:从 [软考系统架构师索引](软考系统架构师索引.md) 进 —— 先看 [软考备考总览](软考备考总览.md) 搞清考试形式与备考路线,再按「按科目学」/「按场景查」直达对应篇目。

## 内容体例

- **知识点小节**:是什么 → 为什么这么设计 → 源码 → 对比同类 → 常见追问 → 通用概念
- **算法题解**:题目 → 思路 → 代码 → 复杂度 → 边界条件 → 变式 → 易错点 → 面试追问 → 关联题
- **英语篇目**:学习地图(首节,全篇导航)→ 分场景章节 → 常见追问 → 相关
- **软考篇目**:学习地图(首节,全篇导航)→ 考试信息/重点分布/知识域章节 → 相关
- **元数据行**:每篇/每节的结构化标注,也是索引页的权威源
  - 八股与算法:`频次 ★★★★ · 难度 🟡 · 高频:字节/美团`
    - 频次:★★★★★ 必考 / ★★★★ 高频 / ★★★ 常见 / ★★ 偶考
    - 难度:🟢 易 / 🟡 中 / 🔴 难
  - 英语学习:`等级 L2 · 每天 15 分钟 · 场景:写PR→二、PR 描述`
    - 等级:L1 看文档 / L2 写邮件PR / L3 能聊天 / L4 能开会 / L5 自如
    - `场景→小节` 决定它出现在英语索引「按场景查」的哪一行
  - 软考系统架构师:`科目 综合知识/案例分析/论文 · 考频 ★★★★★ · 场景:报名→一、考试基本信息`
    - 科目:考试三科(综合知识选择题 / 案例分析问答题 / 论文写作题)
    - 考频:★ 1~5 颗,★ 越多越常考/备考优先级越高
    - `场景→小节` 决定它出现在软考索引「按场景查」的哪一行
