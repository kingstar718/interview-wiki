## 一、怎么读这张表

- 分值范围是 2025 新版大纲后近几次考试的多来源统计区间（希赛/中培/复习指南交叉核对），每年有 1~3 分波动，别当精确值
- ★ 是**备考优先级**（越靠前越先投入），不是考试占比——比如专业英语只有 5 分但是固定送分，优先级高于只有 0~3 分的数学
- 「架构核心 = 软件架构设计 + 软件工程」是全卷的命脉：占比常年 45%~55%，案例分析、论文也绕不开

## 三、重点知识域详解

### 软件架构设计：全卷心脏

- 必考：架构风格（数据流/调用返回/独立构件/虚拟机/仓库）识别与选择——几乎每年 2~4 题
- 质量属性：性能/可用性/安全性/可修改性，以及场景六要素（刺激/来源/环境/构件/响应/响应度量）、ATAM 等评估方法
- 4+1 视图与 UML 建模、ADL（架构描述语言）、中间件分类
- 答题语感：给你一段需求，判断该用哪种风格/策略——这是案例必答题的同款能力

### 软件工程：分值第二、性价比高

- 开发模型（瀑布/原型/螺旋/敏捷/DevOps）与选型
- 需求工程：功能 vs 非功能、用例、需求变更管理
- UML：用例图/类图/序列图/状态图 的适用场景（新版权重下降但仍是基础）
- 软件测试（单元/集成/系统/验收）、软件维护、配置管理与项目管理
- 易丢分点：软件过程改进（CMMI）、遗留系统改造

### 其余知识域：送分题策略

- 专业英语（5 分）：考前刷一遍架构英文术语表即可
- 法律法规（3 分）：著作权保护期/侵权判定是高频，背表
- OS 与组成（3~7 分）：前趋图/PV、银行家算法、位示图是计算题，练熟就稳
- 数据库（2~5 分）：规范化（候选键/范式判断）必练
- 可靠性（0~3 分）：串联/并联/混联可靠度公式，背公式即得分

## 四、案例分析题型分布

5 道大题，第 1 题必答 + 后 4 题选 2，每题约 25 分，总 75 分。

| 常考方向 | 频率 | 说明 |
|---|---|---|
| 软件架构：风格识别/质量属性与权衡 | 几乎必考（常为必答题） | 质量属性场景六要素、架构风格判断、敏感点/风险点/权衡点 |
| 数据库与数据架构 | 高频 | 数据库设计、缓存设计、分布式数据一致性 |
| 云原生/微服务/大数据 | 高频（新大纲后上升） | 容器化、Serverless、大数据 Lambda/Kappa 架构 |
| 嵌入式/通信系统 | 常考 | 软硬件协同、微内核、总线与通信协议 |
| Web 应用/系统设计 | 常考 | 分层架构、性能与可用性设计 |
| 安全架构/DDD 限界上下文 | 偶考但必答风险高 | 安全策略落地、领域建模 |

2025 下半年真题回忆：必答题是质量属性场景（效应树 + 场景六要素）；选答题出现限界上下文与餐饮系统架构（DDD）、云原生数据库、秒杀场景、性能测试——和上表的重点完全一致。

## 五、论文主题分布

论文近年 4 选 1，2500~3000 字。考纲方向：系统建模、软件架构设计、基于架构的开发方法、系统设计、可靠性、安全保密性。

| 近年论文题 | 主题归类 |
|---|---|
| 论基于云原生数据库的企业信息系统架构设计（2025 下） | 新技术 + 数据架构 |
| 论无服务器架构（Serverless）设计和应用（2025 下） | 新技术 + 架构选型 |
| 论软件系统的性能测试（2025 下） | 工程实践 |
| 论秒杀场景及其技术解决方案（2025 下） | 高并发系统设计 |
| 论云原生架构及应用（2024 下） | 新技术 + 架构 |
| 论大数据 Lambda 架构（2024 上） | 数据架构 |
| 论模型驱动架构设计方法及其应用（2024 上） | 架构设计方法 |
| 论单元测试方法及应用（2024 上） | 工程实践 |

规律：新技术（云原生/Serverless/大数据）占半壁江山，且都要求落到**真实项目背景 + 架构决策 + 质量属性验证**——论文不是默写考点，是讲一个「你怎么做架构决策」的故事。

## 六、按知识域刷题策略

| 优先级 | 时间投入 | 知识域/科目 | 理由 |
|---|---|---|---|
| P0 | 25% | 软件架构设计（综合 + 案例） | 分值最大，且案例必答、论文都用得上 |
| P1 | 20% | 软件工程 | 分值第二，性价比高 |
| P1 | 15% | 案例分析专项（质量属性/架构风格/数据库设计） | 三科里最容易练出答题姿势 |
| P2 | 10% | 数据库/OS/网络/安全 | 综合知识保底分 |
| P2 | 10% | 论文素材与模板 | 提前备 2~3 个项目素材，每周动笔一次 |
| P3 | 10% | 专业英语/法规/可靠性等小分块 | 考前两周背表送分 |
| P3 | 10% | 真题整卷模拟 | 穿插进行，第 3 周起每两周一套 |
