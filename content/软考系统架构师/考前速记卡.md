## 一、计算题公式

| 考点 | 公式/要点 |
|---|---|
| 可靠度（串联） | R = R1 × R2 × … × Rn，部件越多越不可靠 |
| 可靠度（并联） | R = 1-(1-R1)×(1-R2)×…×(1-Rn)，冗余提高可靠度 |
| 可用性 | A = MTBF / (MTBF + MTTR) |
| 磁盘容量 | 磁头数 × 柱面数 × 扇区数 × 每扇区字节数 |
| 磁盘存取时间 | 寻道时间 + 旋转延迟 + 传输时间 |
| 子网可用主机数 | 2^(32-前缀) - 2（去掉网络号与广播地址） |
| 位示图换算 | 字号 i=(块号-1)÷字长+1，位号 j=(块号-1) mod 字长 |
| 银行家算法 | Need = Max - Allocation；找可推进进程构成安全序列 |
| 关键路径 | 网络图中最长路径，其上浮动时间为 0 |
| 页面置换 | FIFO 有 Belady 异常；LRU/OPT 是栈式算法，无 |

## 三、架构风格特征速查

| 风格 | 特征词 |
|---|---|
| 管道-过滤器 | 数据流、逐级处理、可重用 |
| 事件驱动（隐式调用） | 异步通知、松耦合、顺序难保证 |
| 解释器/虚拟机 | 可移植、灵活、性能差 |
| 黑板系统 | 无确定算法、共享数据区 |
| 层次结构 | 分层、逐层调用、可替换 |
| 仓库 | 共享数据中心、中心瓶颈 |
| 微服务 | 独立部署、按业务拆分、分布式复杂度高 |

## 五、高频易错点

- **对称 vs 非对称**：AES/DES/RC5 对称，RSA/ECC 非对称；数字签名用**私钥**签
- **内聚耦合方向**：内聚越高越好（功能内聚最好），耦合越低越好（非直接耦合最好）——别记反
- **六要素 vs 评估概念**：权衡点/敏感点/风险点是 ATAM 评估概念，不是场景六要素
- **4+1 视图对应**：类图→逻辑视图，部署图→物理视图，序列图→进程/场景，别混
- **可靠度直觉**：并联结果比单个高、串联比单个低，算完检查一下
- **关键路径**是「最长」不是最短
- **子网主机数**要减 2（网络号 + 广播地址）
- **专业英语 5 分**是固定送分，别放弃

## 六、考前三天怎么用

| 时间 | 做什么 |
|---|---|
| 考前第 3 天 | 过一遍计算题公式表，每一类各手算一题（可靠度/子网/位示图/关键路径） |
| 考前第 2 天 | 背法律期限 + 风格特征 + 战术对照；案例答题模板默写一遍 |
| 考前第 1 天 | 只过高频易错点 + 论文素材；不学新知识，保证睡眠 |
| 考前 | 确认身份证/准考证；提前用官方模拟熟悉机考系统 |
