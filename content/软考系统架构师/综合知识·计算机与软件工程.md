## 一、计算机系统基础：组成原理与性能评价

- 磁盘：容量 = 磁头数 × 柱面数 × 扇区数 × 每扇区字节数；平均存取时间 = 寻道时间 + 旋转延迟 + 传输时间
- 系统性能指标：主频、IPS/MIPS/MFLOPS、吞吐率 vs 响应时间；基准测试程序（SPEC、TPC）
- 高频考法：给磁盘参数算容量/存取时间；给主频算 MIPS

## 二、操作系统：必考计算题

### 前趋图与 PV 操作

- P 操作申请资源（信号量减 1，小于 0 则等待），V 操作释放资源（加 1，不大于 0 则唤醒）
- 互斥：信号量初值 1；同步：初值 0 或资源数量
- 真题：给前趋图补 PV、判断死锁风险

### 死锁与银行家算法

- 死锁四条件：互斥、持有并等待、不可剥夺、循环等待
- 银行家算法：Need = Max - Allocation，找能推进的安全序列（安全状态判断）

### 段页式存储与页面置换

- 页式：逻辑地址 = 页号 + 页内偏移，查页表得物理地址
- 段式：逻辑地址 = 段号 + 段内偏移；段页式两层转换
- 置换算法：OPT（最优）/ FIFO / LRU / Clock；FIFO 存在 Belady 异常
- 真题：算缺页次数、地址转换

### 文件系统

- 索引文件：单级/两级/混合索引，求最大文件大小
- 空闲块管理：位示图（字长 n，块号 → 字号/位号）、成组链接法

## 三、计算机网络

- OSI 七层 vs TCP/IP 四层对应：应用/传输/网络/链路；常见协议端口（HTTP 80、HTTPS 443、DNS 53、FTP 21）
- 子网划分：CIDR 前缀 → 主机数 = 2^(32-前缀) - 2；给 IP 求网络号/广播地址
- 安全协议层次：TLS（传输层之上）、IPSec（网络层，VPN）、SSH（远程登录）
- 高频：TCP 三次握手/四次挥手、UDP vs TCP、IPv6 128 位

---

## 四、数据库系统

- 三级模式两级映像：外模式/概念模式/内模式；逻辑独立性与物理独立性
- 关系代数：选择 σ、投影 π、连接 ⋈；对应 SQL 写法
- 规范化：函数依赖；1NF/2NF/3NF/BCNF 判断；候选键求法（只在函数依赖左边出现 + 闭包覆盖全部属性）
- 事务：ACID；并发问题（丢失更新/脏读/不可重复读/幻读）；封锁与两段锁协议
- 分布式数据库：水平/垂直分片、数据复制；CAP 简述
- 数据仓库：ETL、星型/雪花模型、维与度量、OLTP vs OLAP
- 高频考法：范式判断、候选键、SQL 关系代数互转

## 五、软件工程

- 开发模型：瀑布/原型/螺旋/增量/迭代/敏捷（Scrum）；选型题——需求不确定用原型/敏捷，高风险用螺旋
- 需求工程：获取 → 分析 → 规格说明 → 验证；功能 vs 非功能；用例
- UML：结构图（类/对象/构件/部署/用例）vs 行为图（序列/状态/活动/协作）；与 4+1 视图的对应
- 软件设计：内聚由高到低（功能/顺序/通信/过程/时间内/逻辑/偶然）、耦合由低到高（非直接/数据/标记/控制/外部/公共/内容）——**高内聚低耦合**
- 测试：单元/集成（自顶向下/自底向上）/系统/验收；黑盒（等价类/边界值/判定表）vs 白盒（语句/判定/条件/路径覆盖）；V 模型
- 维护四类：改正性/适应性/完善性/预防性
- 软件过程：CMMI 五级（初始/已管理/已定义/量化管理/优化）
- 遗留系统：重构/正向工程/逆向工程/再工程

## 七、法律法规、标准化与专业英语

- 著作权：自然人作品保护期终身 + 50 年，法人作品 50 年；职务作品归属约定优先
- 专利：发明 20 年、实用新型 10 年、外观设计 15 年
- 商标：10 年、可续展；商业秘密靠保密措施
- 标准分级：国际/国家/行业/地方/企业；强制（GB）vs 推荐（GB/T）
- 专业英语（5 分）：主题固定（架构风格/信息系统/DFD/软件过程），背架构术语表、按关键词读题
