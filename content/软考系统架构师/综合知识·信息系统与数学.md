## 一、系统工程与信息系统基础

- 信息系统分类（高频判断题）：
  - TPS 事务处理系统（订单/记账）
  - MIS 管理信息系统（报表、统计分析）
  - DSS 决策支持系统（模型库 + 数据库支持决策）
  - ES 专家系统（知识库 + 推理机）
  - OAS 办公自动化系统
- 信息系统战略规划方法：诺兰模型（六阶段成长）、企业系统规划法 BSP、关键成功因素法 CSF、战略集合转化法 SST
- 企业应用集成 EAI：数据集成 / API 集成 / 消息集成 / 门户集成；SOA 是服务级集成的主流方式
- 考点：给系统描述判断类型；规划方法名称与特点连线

---

## 二、企业信息化与电子政务/商务

- 企业信息化系统：ERP（企业资源计划）、CRM（客户关系管理）、SCM（供应链管理）、BI（商业智能）
- 电子商务模式：B2B / B2C / C2C / O2O（线上到线下）
- 电子政务模式：G2G（政府对政府）、G2B（政府对企业）、G2C（政府对公民）、G2E（政府对雇员）
- 考点：模式判断（如「企业对消费者」= B2C）；ERP 与 CRM 的边界（内部资源 vs 客户关系）

## 三、数学与经济管理

- 线性规划：目标函数 + 约束条件，图解法求顶点最优值；考法就是给约束求最值，代入各顶点比较
- 数学建模：问题分析 → 模型假设 → 模型建立 → 求解 → 检验；考概念排序
- 盈亏平衡：收入 = 成本 求保本产量/价格；利润 = 收入 - 固定成本 - 变动成本
- 投资分析：净现值 NPV（正则可行）、投资回收期
- 考点：简单线性规划（1~2 题）、盈亏平衡计算
