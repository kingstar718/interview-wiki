## 专题主线笔记

把题串起来记，比单独刷更牢：

**主线一 —— 「固定一端，另一端唯一确定 → 查表 O(1)」**
`P1 两数之和` → `P560 和为 K 的子数组`
P1 固定 x 后要找 `target - x`；P560 把区间和改写成前缀和之差后，
固定右端点就要找 `prefixSum - k` —— 完全同构，P560 只是多了「计数」和「空前缀」两层包装。

**主线二 —— 「避免重复计算，把 O(n²) 压回 O(n)」**
`P128 最长连续序列` → `P3 无重复字符的最长子串`
P128 靠「只从没有左邻居的起点扩展」，P3 靠「左指针只进不退」，
本质都是保证每个元素在内层循环里总共只被访问一次。

**主线三 —— 「哈希表不只用来查，还能用来分组」**
`P49 字母异位词分组`
思路从「两两比较」转向「给每个元素算一个代表元(指纹)」，是哈希表的另一类用法。
